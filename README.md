# cma-cnv-release

マイクロアレイCNV解釈支援アプリ（染色体マイクロアレイ検査で報告された CNV について、
公開データベースの情報を整理して専門医の解釈を支援するツール）の **版情報だけ** を置く
リポジトリです。

アプリ本体のソースコードはここには含まれません（別の非公開リポジトリで管理しています）。

## version.json

配布したアプリが起動時にこのファイルを読み、新しい版が出ていれば画面で知らせます。
アプリが送る情報はありません（このファイルを読むだけです）。

| 項目 | 意味 |
|---|---|
| `latest` | 最新の版 |
| `published` | その版を公開した日 |
| `min_supported` | この版より古いものは使用を推奨しない（採点の不具合などで回収する場合に上げる） |
| `notes` | 利用者に伝える短い説明 |
